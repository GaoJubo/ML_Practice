📌 项目简介

本项目是一个用于记录和实践机器学习（Machine Learning）相关内容的练习仓库，主要用于：

📊 学习机器学习基础理论与算法
🧪 实现经典算法与实验
📓 记录学习过程中的 Notebook 实验
🚀 提升实际建模与数据分析能力

项目以 Jupyter Notebook 为主要形式，强调“边学边做”的实践路径。

🧠 项目内容

本仓库主要包含以下内容（根据典型 ML Practice 项目结构整理）：

1. 基础算法实现
线性回归（Linear Regression）
逻辑回归（Logistic Regression）
KNN / SVM 等基础模型
决策树与集成方法

1. 数据处理
数据清洗（Data Cleaning）
特征工程（Feature Engineering）
数据可视化（Matplotlib / Seaborn）

1. 深度学习（可能包含）
PyTorch / TensorFlow 基础
简单神经网络实验

1. 实验记录（Notebook）
每个实验以 .ipynb 形式保存

包含完整流程：

数据加载 → 数据预处理 → 模型训练 → 评估 → 可视化



⚙️ 环境依赖

建议使用 Python 3.7+

安装依赖：

pip install numpy pandas matplotlib scikit-learn jupyter

如果使用深度学习：

pip install torch torchvision

🚀 使用方法
克隆仓库：
git clone https://github.com/GaoJubo/ML_Practice.git
cd ML_Practice
启动 Jupyter Notebook：
jupyter notebook
打开对应 .ipynb 文件运行实验


⚠️ 注意事项
本项目偏向学习记录，非生产级代码
